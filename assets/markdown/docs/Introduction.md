# Introduction to Sherkety App

Welcome to the Sherkety App, a platform designed to streamline the process of company registration and management. This document provides an overview of the app's architecture, core functionality, and primary components.

## Project Overview

Sherkety App leverages the Flutter framework and Firebase backend to deliver a seamless experience for users, utilizing Riverpod for state management within an NX workspace structure. This modular setup allows for reusable components and scalable code management.

## Key Modules

1. **Authentication**: Secure user login and registration.
2. **Company Registration**: Step-by-step guided process for creating a new company.
3. **UI Library**: Reusable widgets and layouts that maintain visual consistency.

## Technology Stack

- **Flutter**: Frontend framework.
- **Firebase**: Backend and authentication.
- **Riverpod**: State management.
- **NX.dev**: Monorepo management.

This app adheres to best practices in modular code design and aims to deliver a smooth user experience.
