# Usage Guide for Sherkety App

This document details the primary features and workflows within the Sherkety App, guiding you through authentication, company setup, and navigation.

## Key Workflows

1. **User Authentication**

   - Secure login and registration are handled via Firebase. Users can log in, sign up, or reset their passwords.

2. **Company Registration Process**

   - A multi-step process assists users in setting up a new company. This process includes:
     - Company Type Selection
     - Company Name and Details
     - Founders and Investment Capital
     - Address and Activities

3. **Home Screen Navigation**
   - Users can view company details, edit settings, and access various features through a bottom navigation bar.

## User Interface Components

- **Auth Layout**: Simplified login and registration screens.
- **Info Layout**: Displays content pages such as "About" or "Help."
- **Company Layouts**: For creating and viewing company details.

The app is designed to provide a fluid and intuitive experience, leveraging modular components from the UI library.
